SECURITY REMINDERS

  1. The Garmin Secret `{{ .Values.garminSecret.name }}` is NOT created by this chart.
     If it does not exist in this namespace, the ingest pod will remain stuck in
     CreateContainerConfigError. Check:

       kubectl get secret -n {{ .Release.Namespace }} {{ .Values.garminSecret.name }}

  2. A Kubernetes Secret is base64-encoded, NOT encrypted. The Garmin Secret
     is equivalent to full account access.

  3. The PostgreSQL password is the one YOU provided
     ({{ if .Values.postgresql.auth.existingSecret }}pre-existing Secret `{{ .Values.postgresql.auth.existingSecret }}`{{ else }}`postgresql.auth.password`{{ end }}).
     It is never regenerated by the chart. Keep it: it is frozen in the
     PostgreSQL data volume from first startup, and changing it in the values
     does NOT change it in the database (you need an ALTER USER).
{{- if .Values.mcp.enabled }}

  4. The MCP Bearer token lives in Secret {{ include "t0.mcp.bearerSecretName" . }}
     {{- if .Values.mcp.auth.bearerTokenExistingSecret }}(pre-existing, referenced only){{ else }}(created from `mcp.auth.bearerToken` -- keep it OUT of any committed values file){{ end }}.
     The read-only DSN Secret `{{ include "t0.mcp.dsnSecretName" . }}` is NOT created by
     this chart: if it does not exist in this namespace, the MCP pod will remain
     stuck in CreateContainerConfigError. Check:

       kubectl get secret -n {{ .Release.Namespace }} {{ include "t0.mcp.dsnSecretName" . }}
